# 🧠 Neuro-Atlas v2.0 | Clinical Visualization

[![Live Demo](https://img.shields.io/badge/View-Live_Demo-4facfe?style=for-the-badge)](https://jordanhucks.github.io/neuro-atlas-v1/)

An interactive, web-based 3D anatomical brain visualizer engineered for clinical mental health education and neuroscience research. This application provides a high-performance, zero-dependency environment for visualizing key brain structures and their associated clinical functions.

## ✨ Features

* **Interactive 3D Environment:** High-fidelity anatomical model visualization powered by Three.js.
* **Clinical Annotations:** Permanent "Glass UI" cards mapped to specific 3D coordinates, providing immediate functional data for:
    * **Frontal Lobe:** Executive function and emotional regulation.
    * **Temporal Lobe:** Auditory processing and memory consolidation.
    * **Parietal Lobe:** Sensory integration and spatial awareness.
    * **Cerebellum:** Motor control and cognitive regulation.
* **Zero-Install Deployment:** Hosted via GitHub Pages for instant access on any desktop or mobile browser.
* **Educational Utility:** Designed for use in clinical counseling and neuro-rehabilitation settings.

## 🛠️ Technical Stack

* **Three.js:** 3D Rendering Engine.
* **CSS2DRenderer:** Integrated HTML/CSS labeling system.
* **GLTFLoader:** 3D Asset Pipeline.
* **GitHub Pages:** Cloud Hosting.

## 🚀 Navigation

1. Click the **Live Demo** badge above.
2. **Left Click + Drag:** Rotate the model.
3. **Right Click + Drag:** Pan the camera.
4. **Scroll Wheel:** Zoom in/out to inspect internal structures.
